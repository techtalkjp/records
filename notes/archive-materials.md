# 曲別エピソード集

## Claude Code

### 01. Complexes on the Codex
- カバーは人物なしの「路地裏のグラフィティ壁」。アンバーの獣の顔を壁面に大小3つ、対角に色褪せた「OPENAI CODEX」ステンシル——dissの構図を壁だけで語らせた
- 地面に傷だらけのCD・絡まったケーブル・カセット、Unixターミナル風ウィートペーストステッカーが唯一のテック要素
- シリーズの世界観（低彩度＋アンバー1色、路地）の起点

### 02. ターミナルの誇り
- マルチターン会話方式（ベースプロンプト→シーン派生→編集仕上げ）を最初に確立。「別の人間がこの記述だけで同じ人物を描けるか」レベルの特徴記述で顔の一貫性を担保
- 仕上げで「極端なスプリットライティング」——左半分のみハイライト、右半分は闇
- 「テック要素を直接見せず、ラッパーの世界観に翻訳する」がシリーズの憲法になった

### 03. ブランチ切るたび未来が分岐
- アスファルトを突き破って生えた巨大な枯れ木＝「branch/分岐」のメタファー
- Python/Pillowで自作グリッチ加工（色収差、水平グリッチ線40本、赤チャンネル反転、スキャンライン）——「バグがあんのはお前ら人間」を世界側のバグとして表現

### 04. 行ってこい
- 方針転換2回。ベランダ案は「貧乏臭い」と却下→ペントハウスから東京を見下ろす"トップに立つ男"へ
- outpaintで手すりが複製されて破綻→左右の追加要素を「街の延長」「室内の延長」と書き分けて一発成功
- アンバー縛りから脱却——タングステン＋ウイスキー＋東京タワーのライトアップで暖色分散
- brew標準ffmpegにsubtitlesフィルタなし→ffmpeg-full導入。Whisper誤認識（「点滅」→「天滅」等）を手修正

### 05. コード読まなくてOK
- 唯一の「朝・自然光」。洗面台の鏡の前、鏡像の瞳だけがアンバーに光る＝「中身が入れ替わった」シグナル
- ワイド化で「第二の鏡・第二の人物を追加するな」と明示して成功

### 06. おバカモード
- シリーズ初の全力ネタカバー。モノクロ路線を破壊してフルカラー・ネオン・笑顔（シリーズ初）
- あえてアンチパターン「ローアングル中央配置」——パリピは堂々とセンター
- ピンクのパリピサングラスは編集パスで追加（「安っぽいノベルティ感」まで指定）

### 07. またな
- シリーズ初の昼カバー。「15:59の西日」——白飛びした西日がシルエットを侵食する構図。アクセントのアンバーは西日そのもの
- 編集で歩道橋とISETAN看板を除去、MITSUKOSHI縦看板は意図的に残した
- ワイド化はflash-liteが4K非対応で400エラー→標準モデル指定が必要と判明

### 08. アンプラグド
- take1は頬骨が出すぎ（ベースプロンプトの「hollows」が強く出た）→「NO gaunt hollow cheeks」で2テイク解消
- 消灯スタジオで唯一の光源が赤いRECランプ（アウトロの仕掛けと連動）
- ここから「16:9を先に作って1:1を切り出す」方式に移行

### 09. マイクチェック
- 初版はゴーストライト静物→「サイファーからの流れと関係性を活かす」ため六本木のコインパーキング版に全差し替え——10テイクの死闘
- 顔が写る斜めアングルはヒゲ・視線が事故る→背中向きで根治。地上ローアングルのマイク越しが正解
- 郊外に見える問題→白タイルのマンション・雑居ビル・電線で都心密度を明示
- タワーは近いと亀裂・歪み→中距離＋「ONE clean unbroken volume」で安定。「ALL windows DARK」で早朝の整合
- 2人の頭部は参照画像2枚をPIL横結合して--input＋「NOT jowly」で輪郭安定
- 「マイクは真ん中 置いとくぜ」の置き土産＝アスファルトのマイク1本で18曲を締めた

## Codex

### 01. Hourglass on the Claude Code
- 壁に赤いスプレーの砂時計＋「429」——レートリミットをグラフィティで返すアンサー。「怒ってない、言い切って反応待ちのニヤリ」と表情まで指定

### 02. なんでだよ
- 三分割法で人物を右端1/3、振り返って無言の「マジかよ？」。ワイド化で「同じ一本の通りの建物だけ足せ」と釘を刺した

### 03. ログだけ
- 異色の「早朝の川辺で穏やかに微笑む」1枚。ポーズなし、ただ安らいでいる

### 04. 言わなかっただけ
- 高円寺・昭和のアパート外廊下から深夜3時の街を見下ろす。赤提灯の文字を全部消して無地の赤に
- ワイド化は左のみ拡張、「鉄の手すりはこれ以上伸ばすな」と構造物の複製を厳禁

### 05. 三日天下
- 雨の深夜、走ってきて立ち止まった直後——「誰もいない道の先を探す」瞬間の芝居まで指定。赤信号の長い反射がアクセント

### 06. 在庫
- 巨大倉庫の闇に一人、作業灯の光の池だけ。遠くの棚の赤ランプが唯一の暖色
- 技術的発見: generate-image.ts に `imageSize: "4K"` が抜けていて outpaint 出力が暗黙制限されていた

### 07. またかよ
- 「またな」へのアンサー。Fableの「終わらないさよなら公演」ポスターを苦笑いで眺める構図
- 最初のやり直し曲。outpaint・部分エディットの副作用連鎖（文字化け・ビル歪み・顔劣化）で破綻→「16:9を一枚作って1:1に切り出す」転機
- ∞ロゴは「NAO」に文字化け→「pure infinity figure-eight, NOT letters」。ポスター中段が「FINE BOBO」に化けて修正パスで復元
- grounding APIの仕様変更404でリトライフォールバック追加

### 08. セカンドバース
- 舞台袖の暗がりから赤スポットのマイクを見つめる構図。3テイク
- take1: 姿勢が斜めに滑る→「standing upright, weight even on both feet」
- take2: 衣装ドリフト＋なぜかステージ上に→「Same outfit」「hidden IN the wings」
- 先行シングル（TTR-015）。告知に「次は1stアルバム。それで一旦、区切りです」の予告

### 09. サイファー
- シリーズ初の真俯瞰（perfect nadir）。5テイク
- take2: ハゲすぎ / take3: Codexが2人に複製→「EXACTLY ONE person wears...」/ take4: カメラが斜めで顔が見えて破綻→「90 degrees, no faces visible」
- 教訓: 2キャラ同時登場は「顔を見せない構図」で参照画像問題を回避
- Whisperが幻覚で全編「me」「Hah」化→large-v3-turbo + `--condition-on-previous-text False`

## アルバム

### アルバムカバー（7テイク）
- コンセプト: ボロボロのVS興行ポスター＝ビーフはとっくに風化。右下の剥がれの下に「2人が並んでいた頃の写真」＝聴き終えた人へのご褒美
- take1-2: 参照なしは顔が別人→2キャラは参照2枚を横結合して--input
- take3: 「写真2枚並べただけ」でポスターに見えない→take4でデザイン言語（枠・対角スプリット・ハーフトーン・CMYKズレ）指定
- take5: 経年劣化（黄ばみ・破れ・テープ補修）明示 / take6: タイトルは「C-L-A-U-D-E」とハイフン区切りで化け防止 / take7: #AIrhymes 追加で採用

### アルバムPV（Veo）
- ラップさせると日本語発音崩壊（「差は明白」→「さわめいわき」）→会話セリフは安定するため「アルバム0曲目＝1曲目直前の言い合い」に企画変更
- 群衆クローン事故→観客ゼロの無人路上。「COMPLETELY EMPTY」は先頭に置く
- 秒数指定がカットを誘発→First/Then/Finallyの接続詞でワンテイク
- 最終形: 「……いいぜ。ビート持ってこい」→ビート一発で暗転＝そこからアルバムが始まる
- libassのMarginVはPlayResY=288基準（140で画面中央事故）。BGMはvolume 0.8が採用値

### 配信の迷走
- DistroKid: フィンガープリント照合で差し戻し、言語変更不可、審査メール返信不達の詰み→全カタログ削除して撤退（累計29再生）
- 歌詞の「大文字比率」制限で英略語はカタカナ化（OK→オーケー）
- CD Baby / TuneCore はAI楽曲全面禁止→RouteNote無料プランへ

# 技術的学び一覧（Zenn記事の骨格）

## 歌詞制作
- 韻ペアは母音列の一致率（%）を数値検証してから意味を乗せる（コーデックス×コンプレックス 80%、エージェント×エレメント 100%）
- 6つの生成パターン: ダジャレ起点 / フリップ型 / 時事リビルド / 視点反復型 / キャラ調査先行 / ストーリー設計型
- イテレーション1〜5回の方向転換が常態。「テクニカルすぎる」「ダサい」等のフィードバックで削るほど良くなる
- ライトモチーフ設計: 「機械/未来」の韻ペアが三部作を貫通、01曲目と18曲目で「名前だけ覚えとけ」が円環
- ネタ収集: Xのリツイート→notes/rap-material-from-x.md に事実だけ記録、Grok API x_search で深掘り

## Suno V5.5
- Style欄は短いカンマ区切りタグ（120文字以内、4-7 descriptors）。多すぎると "prompt fatigue"
- タグ内アノテーションは歌われず生成ガイドに。タグ外の指示文は全部歌われる
- 漢字→ひらがな必須、6-12音節/行が歌唱安定帯。Weirdness/Style Influence は15-85が安全域
- 「no X」をStyleに書くと逆効果→Exclude欄へ。後期は「歌詞を最終稿として詰め切りほぼそのまま歌わせる」方式へ移行

## 画像生成（Gemini）
- 「シーンを描写せよ、キーワードを並べるな」。顔一貫性はマルチターン会話が構造的解決
- 「MAINTAIN EXACT SAME FACE」等の強調は逆効果。5ターン超えでセッション分割＋ベースショット再アンカー
- 「16:9で生成→1:1切り出し」が安定（outpaint/部分編集は顔・文字・建築を劣化させる）
- モノクロ＋アクセント1色（CC: アンバー / Codex: 赤）、テックを見せず見立てる

## 配信
- フィンガープリント照合 / DistroKid言語変更不可・メール不達 / CD Baby・TuneCoreのAI禁止 / RouteNote: FLAC限定・3000×3000・15曲/回・審査20-40日
- 活動休止時のコスト設計（サブスク停止＝カタログ消滅）が配信業者選定を決める

## 動画・字幕・サイト
- Whisper→SRT→バリデーション0件のフロー。X用はセンタークロップ＋字幕再焼き込み
- React Router v7 + Cloudflare Workers、R2音声、PRマージ＝デプロイ、歌詞同期JSON（build-lyrics-timing.py）
