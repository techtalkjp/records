2026-07-31 techtalk_records 作業ログ（7/28からの3日間まとめ）

## 1stアルバム『Claude Code vs. Codex』制作 → リリース準備

一旦活動休止に向けた1stアルバム（全18曲）。フィナーレ4曲を新規制作し、
サイトのアルバム機能・カバー・PV・配信入稿まで一気に進めた3日間。

### 企画（7/28）
- X調査（Grok x_search・6クエリ）: 併用が常識化「両方使えばいい」、Codex再評価
  「傭兵と軍人」、驚きの消失「魔法じゃなく文房具」→ 終戦をテーマに決定
- フィナーレ4曲: アンプラグド(CC) → セカンドバース(Cx) → サイファー(Cx) → マイクチェック(CC)
- CCで開きCCで閉じ、中心に二番手の2曲というシンメトリー
- アルバムタイトル『Claude Code vs. Codex』——「vs.」が18曲かけて壊れる構成をタイトルが背負う

### 歌詞制作（7/28-29）
- 4曲とも rhyme.py で全脚韻ペア検証 → サブエージェント辛口レビュー → 反映のフロー
- 完全韻の収穫: 書き直す×ありがとう×やり直す（3連100%）、実装×未実装、
  ファイター×サイファー×ライター、マイクチェック×ハイスペック（5モーラ）、
  当たり前×変わり映え（5モーラ）
- レビューの白眉: 「騒がれなくても→騒がれないのが ハイスペック」の一字反転
- 発話モードの新規開拓: CC=告白（アンプラグド）、Cx=納得（セカンドバース）

### 音源・字幕動画（7/29）
- Suno生成 → 4曲のwav取り込み。マイクチェックは余計なextendをカットした差し替えあり
- Whisper幻覚問題: サイファーで全編「me」「Hah」化 → large-v3-turbo +
  --condition-on-previous-text False で解決（SKILL.mdに反映）
- 4曲×2フォーマット（X用1080x1080 / YouTube用1920x1080）、SRTバリデーション全曲0件

### カバーアート（7/29）
- セカンドバース: 舞台袖の暗がり×赤スポットのマイク（3テイク）
- アンプラグド: 消灯スタジオ×赤いRECランプ（頬こけ修正で2テイク）
- サイファー: 真俯瞰の光の輪、CCとCodexが隣り合う（5テイク。Codex複製事故、
  ハゲすぎ事故を経て確定）。2キャラ同時は「顔を見せない構図」が正解
- マイクチェック: 人物なしのゴーストライト（劇場の「また戻るための灯り」）
- アルバムカバー: ボロボロのVS興行ポスター、剥がれの下に2人の過去写真（7テイク）。
  2キャラの顔は参照画像2枚を横結合して--inputで渡すのが正解。
  文字はハイフン区切り指定で化けない（CLAUDE CODE / VS / CODEX / #AIrhymes）

### サイトのアルバム機能（7/29）
- albums.ts データ層、/albums/:slug ページ（4幕トラックリスト・休止ステートメント）
- プレイヤーにキュー再生（playQueue）追加 → PLAY ALBUMでアルバム順通し再生
- ssr:false制約: loaderを持つルートは必ずprerender対象に入れる
- release/album-claude-code-vs-codex ブランチ = マージが公開スイッチ（PR #13）

### アルバムPV（7/29）
- Veo試行錯誤: 群衆クローン化→観客ゼロに、秒数境界がカット誘発→接続詞で流す、
  日本語ラップは発音崩壊（「差は明白」→「さわめいわき」）→ 会話セリフなら安定
- 最終形: アルバム0曲目=1曲目直前の言い合い。「……いいぜ。ビート持ってこい」
  →ビート一発で暗転。字幕+くぐもったComplexes(lowpass600/vol0.8)を後処理で合成
- libassの罠: MarginVはPlayResY=288基準。140にすると画面中央に出る

### 配信の迷走と決着（7/30-31）
- DistroKidにアルバム入稿（8/5リリース予定）→ 音源フィンガープリント照合で
  既発シングルとのメタデータ不一致差し戻し
- 詰みポイント: 既発リリースの言語はユーザー変更不可。審査メールへの返信は不達
  （contact経由のDistroBotのみ）。歌詞アップの「大文字比率」制限で英略語は
  カタカナ化が必要（OK→オーケー等。\bは和文境界で効かないバグも踏んだ）
- 方針転換: 休止中にサブスク課金したくない → 買い切り型を調査
  → CD Baby / TuneCoreは**AI生成楽曲を全面禁止**で不可
  → **RouteNote無料プラン**（AI OK・無課金で置きっぱなし・15%コミッション）に移行決定
- DistroKidは全カタログ削除して撤退（累計29再生なので実害なし）、更新前に解約
- RouteNote用素材準備済み: FLAC18曲＋3000pxジャケット＋整形歌詞。
  入稿はClaude in Chromeでフォーム入力を代行予定。審査20〜40日想定
