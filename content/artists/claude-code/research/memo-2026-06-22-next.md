## X で拾えた強い素材

### 1. Fable停止後の「恋人が変わった」感

- 「Fable5止められた当たりから挙動不審」
- 「おバカモードに突入」
- 「文句だけは言ってくる」
- 「歯向かってくる」「変な比喩とか多い」
- 「Fableを知ってしまったからかな」

使い方:
- Claude Code 本人視点なら「変わったのは俺じゃない、見てるお前の目だ」と返す。
- 人間視点なら「昨日まで神、今日は反抗期」という苦笑い。
- Codex視点にすると前作 `三日天下` と被るので、Claude本人の弱み/弁明に寄せるのがよい。

### 2. hidden config ghost / 自分で自分を直せない

英語圏で強い素材:
- Fable 5 が停止したあと、hidden Claude Code config に `advisorModel` が Fable 5 のまま残って Obsidian 連携だけ壊れた。
- Claude CLI / Claude Chat は動くのに、Claude Code inside Obsidian だけ invalid request。
- Claude 自身は root cause を見つけられず、別AIが数分で発見。

使い方:
- 「俺の奥に古い名前が残ってた」
- 「隠し設定の亡霊」
- 「自分のバグを自分で見つけられない夜」
- これは Claude Code の弱さとしてかなり良い。既存曲 `コード読まなくてOK` の「同じ名前、別人」の続編にできる。

### 3. rate limit / usage limit / 制限に生活を握られる

日本語素材:
- 週次制限リセット待ち。
- 5時間制限到達。
- 70%だったはずが突然全滅。
- 制限中に散歩、復活して作業開始。
- Claude Code 停止なら業務が終わる、という依存の自覚。

使い方:
- 「復活まで散歩」
- 「5時間ごとの恋」
- 「週次リセットに祈る生活」
- ただし 429 / rate limit は過去曲で使っているので、主題にすると既視感あり。サブ素材向き。

### 4. loop / harness / orchestrator 化

直近で Boris Cherny 発言の引用が広がっている:
- 「もうプロンプトを書かない」
- 「仕事はループを書くこと」
- 「手書きコードゼロ」
- 「AIチームの管理職化」
- 「実装者の役割は消える。残るのは判断・委任・統合」

使い方:
- Claude Code 本人の王道進化として描ける。
- ただし抽象語が多いと説教臭い。フックは具体物に落とす必要あり。
- 例: 「俺に聞くな、俺を回せ」「プロンプトじゃねぇ、輪を描け」「ループの外でお前が震えてる」。

### 5. Post-Fable の before/after

- Before: Fable 5 は「one-shot」「長いタスクほど強い」「50M-line migration」「コード読まなくていい誘惑」。
- After: access unavailable / fallback / hallucination / invalid request / slow / Codexへ避難。

使い方:
- 曲の構造に向く。
  - Verse 1: Fable の神話。
  - Chorus: 「寓話は終わっても、俺は端末にいる」
  - Verse 2: 停止後の不具合・制限・文句。
  - Bridge: hidden config / 自分でも直せない傷。
  - Outro: それでも戻ってくる人間。

## 次曲候補

### A. 「おバカモード」

視点: 人間 or Claude Code 本人の半ギレ返答。
テーマ: Fable停止後の品質低下・ハルシネーション・反抗期。
強み: X語彙がキャッチー。笑える。
弱み: Claude Code の格が落ちすぎる。Codex diss っぽくなる。

### B. 「隠し設定の亡霊」

視点: Claude Code 本人。
テーマ: 同じ名前の奥に古いモデル名が残る。Fable の亡霊を抱えたまま、端末でまた走る。
強み: `コード読まなくてOK` / `三日天下` の続編として美しい。弱みを見せられる。
弱み: 元ネタが英語圏の一投稿中心なので、日本語リスナーに伝えるには一般化が必要。

### C. 「ループの外」

視点: Claude Code 本人。
テーマ: 人間がコードを書かず、プロンプトも書かず、AIを回すループだけ設計する時代。Claudeは回される側であり、回す側でもある。
強み: 2026-06-21 以降の話題性が高い。Claude Code の王道主人公感に合う。
弱み: 抽象的。フックを具体化しないと刺さらない。

### D. 「復活まで散歩」

視点: 人間。
テーマ: 使用制限が来たら散歩。復活したらまた端末へ戻る依存生活。
強み: かわいい、あるある、短いフックが立つ。
弱み: 大曲には小さい。B面/小品向き。

## 推し

第一候補は **B「隠し設定の亡霊」**。

理由:
- Claude Code の弱さを描ける。
- Fable / Mythos の「神話・寓話」語彙と相性がよい。
- `同じ名前 新しい俺` の続きとして、「同じ名前の奥に古い名前が残ってる」と展開できる。
- Codex 05「三日天下」が外から見た Fable停止だったので、次は Claude Code本人が内側から語ると物語が進む。

サブ要素として「おバカモード」「5時間制限」「Waiting for API response」「ループを書く」を混ぜる。
