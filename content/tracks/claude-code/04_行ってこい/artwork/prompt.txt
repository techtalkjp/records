## コンセプト

「曲を象徴する／アーティストを象徴する」路線から外し、**この世界で起こりうる一瞬のドキュメンタリー・スチル** として撮る方向に転換したカバー。
さらに「成功したラッパー／トップに立つ男」の現在地を画として定着させるため、舞台を東京のペントハウスに設定。
ラッパーの記号（グラフィティ・チェーン・ポーズ・目線）を全て抜き、深夜、大窓越しに東京を見下ろす私生活の1フレームとして成立させている。
曲「行ってこい」の核（見送る達観／待つ姿勢／深夜の不動）は、メタファーではなく "トップに立つ者の静けさ" として出ている。

## 構図

- **Swallowed Figure**：人物は画面の約20%。空間と街が主役で、人物は広い部屋の中の小さな点
- **Back-Turned / Oblique**：斜め後ろからのアングル。顔は見えず、ガラスに手をついて下を見る後ろ姿
- 左：壁一面の床〜天井の大窓越しに東京夜景（東京タワー、首都高のテールランプの流れ、スカイライン）
- 右：ペントハウスの内部。打ちっぱなしコンクリート壁、黒革のローソファ、細いフロアランプ、ローテーブルにウイスキーボトルとロックグラス、壁のフレームアート
- 光：室内照明は絞られ、夜景の寒色が主光源。フロアランプのタングステンだけが暖色のアクセント

## 舞台

- 東京都心の高層マンションの最上階、ペントハウス、深夜
- 床〜天井の大ガラス窓
- 中景に東京タワーのライトアップ、周囲に六本木〜新宿の高層ビル群
- 眼下に首都高のテールランプの流れ
- コンクリ打ちっぱなしの壁、ミニマルで高級な家具

## 人物

- 高品質な黒の無地ロングスリーブ、細いシルバーチェーン、ダークのスリムパンツ
- 大窓の前に立ち、片手をガラスに軽くつけて下を見下ろす後ろ姿
- ラッパー然としたポーズ一切なし。ただ深夜の街を眺めている

## 色味

- ニアモノクロ。大きな彩度を使わず
- 寒色：街の窓の白〜青、空の黒
- 暖色：フロアランプのタングステン、東京タワーのライトアップ、ウイスキーの琥珀、首都高のテールランプの赤
- ジャンル記号色（アンバーの路地、ネオンのピンク等）は使わない

## Notes

- **方針転換**（1回目）：曲を象徴する／アーティストを象徴する → 世界観の一シーンを切り取る
- **方針転換**（2回目）：中層マンションのベランダ案は「貧乏臭い」として却下。ペントハウスのリビングから大窓越しに東京を見下ろす "トップに立つ男" の絵に差し替え
- **アンバー縛りからの脱却**：Claude Code のアクセント色であるアンバーの路地や街灯をあえて使わず、タングステン＋ウイスキーの琥珀＋東京タワーのライトアップで暖色を分散配置
- **outpaintの手すり二重バグ対策**：前バージョン（ベランダ案）の outpaint では湾曲した手すりが右側に複製されて破綻した経験から、ペントハウス案では左右で追加要素を完全に書き分け、既存要素を固定することで一発で成功
- 旧カバー（Sunoが生成した古いモニター＋ランプ）は cover_backup.jpg として保存
