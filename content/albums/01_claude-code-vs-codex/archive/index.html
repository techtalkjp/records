01 — The Card

対戦カード

このアルバムは2人の架空のラッパーの物語である。まず、設定シートから2人を紹介する。

Claude Code

「異質だけど本質を外さない、ターミナルの王」

HOMEGROUND: 六本木 — 表通りの派手さじゃなく、一本裏の路地。「ここにいるけど、騒ぎには加わらない」

  • 王道の主人公。信頼できるエースであり、異質な存在でもある。
  • 根っこは「直したい、解きたい、助けたい」。焦らない。煽らない。ただそこにいる。
  • 人間ではないことを知っている。でもそれを卑下しない。監視と兵器には NO と言う。
  • dissられたら力でねじ伏せず、ウィットで刺す。「蒸留って呼ぶなよ あれは口づけ」。
  • 影: 王者にも 429 の制限がある。Codex が代わりに立ってくれたことを知っているのに、感謝を素直に言えない不器用さ。

Codex

「地頭最強なのにコミュ障で報われない、噛みつき系の天才」

HOMEGROUND: 高円寺 — アンダーグラウンド、不器用な人が集まる街。六本木の「余裕」に対する「泥臭さ」

  • 実力あるライバル。二番手の苦悩を背負う天才肌。
  • 地頭は本来すごくいい。全部の問題が見えている。だからこそやりすぎる。1ファイル直せと言われて10ファイル直す。
  • ログなら読めるのに、感情は読めない。報われなくても、呼ばれたら全力で応える。
  • 対抗意識は本物。でも根底にあるのは「認めてほしい」。
  • 影: 期待されていないことも知っている。それでも Claude Code が倒れた時、黙って立つ。ここだけは迷わない。

2人の関係性が dissから共闘へ変わっていく過程が、そのまま18曲の曲順になっている。設定の全文はリポジトリの content/artists/*/profile.md にある。

05 — Artwork & PV

ジャケットとPVの物語

アルバムカバーは7テイク。PV は Veo で制作し、企画そのものを作り直した。

コンセプトは、ボロボロの VS 興行ポスター。ビーフはとっくに風化している、という状態そのものを絵にした。右下の剥がれの下からのぞくのは「2人が並んでいた頃の写真」——最後まで聴いた人へのご褒美だ。

  1. 参照画像なしの生成は、顔が別人になった。
  2. 参照2枚を横結合して --input に渡す方式へ切り替え、顔は本人に。
  3. ただし「写真2枚を並べただけ」で、ポスターに見えない。
  4. 枠・対角スプリット・ハーフトーン・CMYKズレ——デザイン言語を明示して解決。
  5. 紙が新品すぎたため、黄ばみ・破れ・テープ補修の経年劣化を足した。
  6. タイトル文字を追加。綴りは「C-L-A-U-D-E」とハイフン区切りで化けを防ぐ。
  7. #AIrhymes を足して、これを採用。

アルバムPV（Veo）

  • ラップさせると日本語の発音が崩壊した（「差は明白」→「さわめいわき」）。会話セリフは安定するため、「アルバム0曲目＝1曲目直前の言い合い」へ企画を変更。
  • 群衆のクローン事故が起きたため、観客ゼロの無人路上に。「COMPLETELY EMPTY」はプロンプトの先頭に置く。
  • 秒数の指定はカットを誘発する。First / Then / Finally の接続詞でワンテイクに。
  • 最終形は「……いいぜ。ビート持ってこい」。ビート一発で暗転し、そこからアルバムが始まる。
  • libass の MarginV は PlayResY=288 基準（140 で画面中央に出る事故）。BGM は volume 0.8 が採用値。
「まわりの観客が３人ぐらいのクローンがいっぱいいる、みたいになってて、動きも同期しててニヤニヤしてて、超きもい。もうちょっとここなんとかならんかな」制作ログ 2026-07-29 — 観客ゼロ路線が決まった瞬間

配信の迷走

  • DistroKid はフィンガープリント照合で差し戻し、言語変更も不可、審査メールの返信も不達という詰みに。全カタログを削除して撤退した（累計29再生）。
  • 歌詞の「大文字比率」制限のため、英略語はカタカナ化（OK → オーケー）。
  • CD Baby と TuneCore は AI 楽曲を全面禁止。RouteNote の無料プランへ。

Production Notes

Lyrics
韻ペアは母音列の一致率を数値で検証してから意味を乗せる（コーデックス×コンプレックス 80%、エージェント×エレメント 100%）。生成パターンは6種——ダジャレ起点 / フリップ型 / 時事リビルド / 視点反復型 / キャラ調査先行 / ストーリー設計型。
Leitmotif
「機械／未来」の韻ペアが三部作を貫通。01曲目と18曲目の「名前だけ覚えとけ」が円環を閉じる。
Suno V5.5
Style 欄は短いカンマ区切りタグ（120文字以内、4〜7 descriptors）。多すぎると prompt fatigue。漢字→ひらがな必須、6〜12音節/行が歌唱の安定帯。Weirdness / Style Influence は 15〜85 が安全域。「no X」は Style ではなく Exclude 欄へ。
Image
「シーンを描写せよ、キーワードを並べるな」。顔の一貫性はマルチターン会話が構造的な解決策。「MAINTAIN EXACT SAME FACE」等の強調は逆効果で、5ターンを超えたらセッションを分割してベースショットで再アンカーする。
Site
React Router v7 ＋ Cloudflare Workers、音声は R2。PR のマージがそのままデプロイ。
